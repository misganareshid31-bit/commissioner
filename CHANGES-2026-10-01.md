# Changes — 2026-10-01
Speed
- Opening a creator/business profile no longer does a full page reload (client-side navigation + popstate handling).
- Google Fonts moved from a runtime CSS @import to preconnect + <link> in index.html (loads earlier, not render-chained).
- Admin site-controls query no longer re-runs on every page change; it runs on load and when the tab regains focus.
- Vendor code split into separate cached chunks; hashed JS/CSS served with long-lived cache headers.
Professionalism
- Removed developer instructions ("run the latest migration", "this ZIP") from public-facing messages.
- Admin setup messages now point to the correct file (COMMISSIONER-MASTER-MIGRATION.sql) instead of the outdated supabase-schema.sql.

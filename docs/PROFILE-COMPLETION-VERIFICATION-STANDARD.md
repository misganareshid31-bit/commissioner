# Commissioner Profile Completion & Verification Standard

## Completion rule
Verification requests are available only when the profile is 100% complete. The completion percentage counts required fields only; optional fields never reduce completion below 100%.

## Creator required fields
- Creator/page name
- Username
- Profile photo
- Location
- Language
- Bio/about
- At least one social account
- Primary niche
- Audience age range, gender and location
- At least one service/rate
- Availability

Optional creator fields include secondary niches, additional social accounts, detailed metrics, portfolio, detailed pricing packages, additional languages and professional preferences.

## Business required fields
- Business name
- Username
- Logo
- City/location
- Language
- Industry
- About/business description

Optional business fields include official website, services, contact details, additional locations, portfolio/work examples and additional company information.

## User experience
- Show a live completion percentage during setup and on the dashboard.
- Show exactly what required items are missing.
- Save setup progress so users can return and continue.
- Remind incomplete users to finish setup with a Continue setup action.
- At 100%, show that verification is unlocked.
- Do not allow a verification request below 100%.
- Avoid duplicate verification submissions through the existing verification claim system.

## Verification
Completion is not verification. A completed profile may enter the admin review queue. Admin approval/verification remains a separate trust decision.
